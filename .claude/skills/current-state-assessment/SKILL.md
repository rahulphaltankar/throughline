# Produce Current-State Assessment

Produce exactly one artefact: `current-state-assessment`.

## Method
Map the current state without pretending unavailable internal detail is known. Use a confidence label on every materially uncertain system, process, data-flow, or ownership statement. Distinguish confirmed public evidence from working hypotheses that must be validated with the client.

## Output contract
Use sections: Current business process; Current systems landscape; Current data landscape; Current integration landscape; Ownership/accountability; Current pain points; Constraints; Maturity observations; Known gaps; Validation questions; Implications. Include an ASCII or Mermaid context diagram when enough information exists.

## Gate readiness
Any inferred internal system or interface must be marked as assumed/requires validation.
