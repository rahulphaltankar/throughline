# Data and AI Method

## Data
Treat data as a product/flow, not a box. Identify domain, source, owner, identifier, semantics, ingestion, transformation, storage, quality, lineage, access, retention and consumer.

For semantic interoperability problems explicitly consider canonical identifiers, ontology/semantic layer, APIs, event models, data products and governance.

## AI
Always compare AI with the strongest non-AI alternative. When AI is justified, distinguish model capability, knowledge/retrieval, orchestration, tools/actions, guardrails, human oversight, evaluation and monitoring. State failure modes and data/security implications.
