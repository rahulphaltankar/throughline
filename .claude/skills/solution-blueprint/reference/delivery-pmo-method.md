# Delivery and PMO Method

Derive: solution → deliverables → workstreams → WBS → tasks → dependencies → resources → duration → milestones → critical path → budget.

Use effort and duration ranges, confidence, estimation basis, assumptions, dependencies and contingency. Do not confuse effort with elapsed time. Identify roles/skills, FTE profile, internal/external split and sourcing assumptions. Separate implementation, transition, licences/infrastructure and recurring operations.
