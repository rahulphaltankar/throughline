# Gates

The next increment should implement gates before autonomous workers.

Required classes:

- Tier 0 — deterministic checks
- Tier 1 — structural predicates over artefacts
- Tier 2 — adversarial review
- Tier 3 — calibrated rubric judgement
- Tier 4 — reality / human validation

A gate should be binary, versioned, testable, and linked to at least one regression case.
